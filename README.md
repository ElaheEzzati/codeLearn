## 🧠 "CODELEARN" — Online Learning Platform bt CODEART team

A front-end educational platform for programming courses that allows users to browse, view, purchase, and manage courses offered by various instructors.

### ✨ Key Features
- Homepage with categorized course listings
- Detailed course pages (instructor info, syllabus, price)
- Shopping cart & simulated checkout process
- User login / registration
- User dashboard to view purchased courses
- Fully responsive design for mobile, tablet, and desktop

### 🛠️ Technologies
- **HTML5** — Page structure
- **CSS3** — Styling & responsiveness
- **JavaScript** — User interactions (cart, course display, etc.)
- **Git & GitHub** — Version control & team collaboration
